# 生鲜梨冷链三维装箱与路径优化一体化算法逻辑

本说明用于 GitHub 开源展示，方法口径以 Word 文档《生鲜梨冷链四箱型三维装箱与路径优化一体化模型方案》为准。系统面向单品类生鲜梨冷链配送，将“箱型选择、三维装箱、车辆路径、货损预测、碳排放核算、准时履约”统一到一个可计算框架中。

## 1. 问题定义

输入数据包括客户订单、门店坐标、要求送达时间、车辆参数、四种周转箱、温度记录、历史货损和碳排放参数。系统输出可执行的车辆路线、箱型组合、R/C/H 三维装车坐标、预计抵达时间、货损率、碳排放和综合成本。

车辆以 BJ5045XLCPHEV2 厢式混合动力冷藏车为测算载体，货厢内尺寸为 `4080 x 2100 x 2100 mm`，额定载重为 `3380 kg`。建模目标不是单纯最短路径，而是在硬约束可行的前提下最小化综合成本。

## 2. 四箱型标准

| 箱型 | 外径 mm | 内径 mm | 梨层数 | 单箱梨数 | 适用场景 |
| --- | --- | --- | ---: | ---: | --- |
| LH-600-140 | 600 x 400 x 140 | 565 x 360 x 120 | 1 | 26 | 精品梨、偏熟梨、尾箱和首站优先卸货 |
| LH-600-220 | 600 x 400 x 220 | 565 x 365 x 210 | 2 | 52 | 常规主箱型，保护性和效率均衡 |
| LH-600-300 | 600 x 400 x 300 | 560 x 365 x 285 | 3 | 78 | 硬度较好、单站数量较大、减少搬运次数 |
| LH-600-340 | 600 x 400 x 340 | 560 x 365 x 325 | 4 | 104 | 硬果、小果、短途整批，需重点控制承压和重心 |

理论整车箱数只代表空间上限，不等于可执行满载方案。实际方案必须同时满足载重、通风、支撑率、承压、重心和卸货可达性。

## 3. 综合目标函数

综合成本函数为：

```text
F = C_transport + C_refrigeration + C_loss + C_carbon + P_time + P_pack
```

- `C_transport`：车辆启用成本、里程成本和载重相关运输成本。
- `C_refrigeration`：行驶制冷能耗、开门补偿和怠速补偿成本。
- `C_loss = sum(Value_i * PredLoss_i)`：MLP 预测货损率转化后的货损成本。
- `C_carbon = CarbonCost(s)`：碳排放成本。
- `P_time`：时间窗惩罚。
- `P_pack`：装箱不可行、支撑不足、阻挡卸货、重心偏移等惩罚。

硬约束包括：车辆边界、额定载重、顶部通风、AABB 碰撞、支撑率、强制时间窗、`OnTimeRate >= 95%` 和首站卸货可达性。

## 4. MLP 货损预测

对每个客户构建特征向量：

```text
z_i = [累计运输时间, 平均车厢温度, 温度波动强度, 累计开门次数, 装载密度, 累计运输距离, 初始成熟度]
```

轻量级两层 MLP：

```text
h1 = ReLU(W1 * z_i + b1)
h2 = ReLU(W2 * h1 + b2)
PredLoss_i = Sigmoid(W3 * h2 + b3)
```

训练目标：

```text
Loss = mean((PredLoss_i - RealLoss_i)^2) + lambda * ||theta||2
```

当真实货损样本不足时，可先用 Arrhenius 品质衰减模型或企业经验规则生成预标注，再用少量真实样本修正。MLP 输出不只是展示指标，而是进入 `C_loss` 和货损阈值约束。

## 5. 三维装箱逻辑

车厢左后下角为坐标原点，车长方向为 X，车宽方向为 Z，高度方向为 Y；现场作业使用 R/C/H 编号。四种周转箱底面均为 `600 x 400 mm`，因此可按标准底面划分二维网格。

候选位置按蛇形规则遍历：奇数排从 `C1` 到 `Cn`，偶数排从 `Cn` 到 `C1`，避免箱体长期集中在单侧造成偏载。装载顺序采用“先送后装、后送先装”，保证首站靠近后门，减少翻箱和错卸。

每个新箱体生成 AABB 包围盒，仅当两个箱体在 X、Y、Z 三个方向区间同时重叠时判定为碰撞。上层箱体支撑率为：

```text
support_ratio = EffectiveSupportOverlapArea / BottomArea
```

支撑率阈值：

- LH-600-140 / LH-600-220：不低于 85%。
- LH-600-300：不低于 90%。
- LH-600-340：不低于 95%。

顶部通风约束为：

```text
TopHeight + VentReserve <= CargoHeight
VentReserve >= 150 mm
```

## 6. GA + 2-opt 路径优化

遗传算法染色体采用客户访问序列编码，例如 `[3, 1, 5, 2, 4]` 表示客户访问优先顺序。系统根据车辆载重、容积、时间窗和装箱可行性，将访问序列切分为一条或多条车辆路线。

适应度函数为：

```text
Fitness = 1 / (F + Penalty + epsilon)
```

`Penalty` 包括超载、超容、装箱不可行、货损率超阈值、准时率不足和强制时间窗迟到。

对 GA 产生的候选路线执行 2-opt 局部搜索。若反转局部路径片段后得到的新路线 `R'` 满足：

```text
F(R') < F(R)
```

且仍满足准时率、装箱、载重、温控和碳排放约束，则接受该局部改进。

## 7. 绿色物流核算

碳排放由行驶排放和制冷/开门补偿能耗组成：

```text
Fuel(s) = Distance(s) * FuelRate / 100 + DoorOpenTime(s) * ColdFuelRate
CO2(s) = Fuel(s) * EF_fuel
CarbonCost(s) = CO2(s) / 1000 * CarbonPrice
```

推荐参数可按实测校准：

| 参数 | 示例值 | 说明 |
| --- | ---: | --- |
| FuelRate | 12 L/100 km | 混合动力冷藏车等效运行油耗 |
| ColdFuelRate | 0.03 L/min | 开门、制冷补偿和怠速等效油耗 |
| EF_fuel | 2.63 kgCO2/L | 燃油燃烧二氧化碳排放因子 |
| CarbonPrice | 80 元/tCO2 | 内部碳价 |

## 8. 综合评分与验收

对通过硬约束校验的候选方案 `s`，综合评分为：

```text
Score(s) = w1*C(s) + w2*G(s) + w3*H(s) + w4*S(s) + w5*U(s) + w6*B(s)
```

其中 `C` 为含碳排放成本的路径成本得分，`G` 为重心偏移得分，`H` 为高度风险得分，`S` 为支撑不足得分，`U` 为卸货阻挡得分，`B` 为箱型适配得分。常规权重可取：

```text
w1=0.35, w2=0.15, w3=0.15, w4=0.15, w5=0.10, w6=0.10
```

建议验收指标：

| 指标 | 标准 |
| --- | --- |
| 订单完成率 | 100% |
| 准时率 | >= 95%，强制时间窗不得迟到 |
| 整车毛重 | <= 3380 kg，建议 <= 3210 kg |
| 顶部通风余量 | >= 150 mm |
| 最低支撑率 | 140/220 >=85%，300 >=90%，340 >=95% |
| 首站阻挡箱数 | 0 |
| 累计开门时长 | <= 60 min |

## 9. 工程实现建议

推荐按模块分层实现：

- `loss_model`：MLP 货损预测，可用 scikit-learn 或 PyTorch。
- `route_solver`：GA 初始化、选择、交叉、变异和 2-opt 局部搜索。
- `packing_solver`：R/C/H 坐标、AABB、支撑率、通风、重心和卸货可达性校验。
- `cost_service`：运输、制冷、货损、碳排放和惩罚成本。
- `report_service`：路径单、箱型组合单、三维装车单、风险复核单和绿色物流报告。

后续可接入真实温度传感器、车辆油耗、历史货损和道路 API，对 MLP 参数、碳排放参数和评分权重进行持续校准。
