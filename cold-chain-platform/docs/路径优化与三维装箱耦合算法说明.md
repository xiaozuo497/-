# 路径优化与三维装箱耦合算法说明

本文档统一采用 Word 方案中的方法口径：MLP 货损预测、GA-2-opt 路径优化、四箱型三维装箱、AABB 碰撞检测、支撑率校验、OnTimeRate 强约束和 CarbonCost 绿色物流核算。

## 1. 为什么路径和装箱必须耦合

生鲜梨冷链配送不能只看最短路径。某条路线即使距离短，也可能因为箱数、载重、通风余量、支撑率、重心偏移或卸货顺序不满足要求而无法执行。系统将“路径可行”和“装箱可行”合并为执行可行性，候选方案只有同时满足时间窗、车辆能力和三维装箱校验后，才会进入最终排序。

## 2. 核心方法

| 模块 | 方法 | 作用 |
| --- | --- | --- |
| 货损预测 | MLP 多层感知机 | 根据运输时间、温度波动、开门次数、装载密度、距离和成熟度预测 `PredLoss_i` |
| 路径全局搜索 | 遗传算法 GA | 生成客户访问序列、车辆分配和候选路线 |
| 路径局部改进 | 2-opt | 反转局部路径片段，若综合成本下降且约束仍满足则接受 |
| 三维装箱 | 网格蛇形填充 + 贪心重心评分 | 生成 R/C/H 坐标，保证先送后装、首站可卸 |
| 稳定性校验 | AABB + 支撑率 | 检查碰撞、悬空、承压和顶部通风余量 |
| 绿色物流 | CarbonCost | 把行驶排放和制冷补偿能耗折算为成本 |
| 履约约束 | OnTimeRate | 准时率低于 95% 或强制时间窗迟到则淘汰 |

| 箱型 | 外径 mm | 梨层数 | 单箱梨数 | 适用场景 | 最低支撑率 |

## 4. 综合目标函数

系统以综合成本最小化为目标：

```text
F = C_transport + C_refrigeration + C_loss + C_carbon + P_time + P_pack
```

其中：

- `C_transport`：车辆启用成本和运输距离成本。
- `C_refrigeration`：制冷能耗和开门补偿成本。
- `C_loss = sum(Value_i * PredLoss_i)`：MLP 预测货损率转化的货损成本。
- `C_carbon = CarbonCost(s)`：碳排放成本。
- `P_time`：软时间窗惩罚。
- `P_pack`：装箱不可行、支撑不足、阻挡卸货等惩罚。

## 5. 求解流程

1. 读取订单、坐标、时间窗、箱型、车辆、温度和历史货损数据。
2. 构建 MLP 特征 `z_i = [累计运输时间, 平均车厢温度, 温度波动强度, 累计开门次数, 装载密度, 累计运输距离, 初始成熟度]`，输出 `PredLoss_i`。
3. GA 生成客户访问序列，并按载重、容积、时间窗和箱数切分车辆路线。
4. 每条路线调用三维装箱校验器，生成 R/C/H 坐标。
5. 装箱模块执行边界、AABB、顶部通风、支撑率、重心和卸货顺序校验。
6. 计算运输、制冷、货损、碳排放、时间窗和装箱惩罚成本。
7. 对优良路线执行 2-opt，只有在 `F(R') < F(R)` 且所有硬约束仍满足时接受改进。
8. 输出最低综合成本且满足 `OnTimeRate >= 95%` 的方案；若无全可行方案，则输出最高准时率方案并标记违约原因。

## 6. 执行输出

系统输出五类结果：

- 路径单：车辆、司机、站点顺序、ETA、单站开门时长和 OnTimeRate。
- 箱型组合单：每站 140/220/300/340 箱数、箱号和梨数量。
- 三维装车单：箱号、目的地、箱型、R/C/H 坐标和固定方式。
- 风险复核单：毛重、支撑率、重心偏移、通风余量和阻挡箱数。
- 绿色物流报告：距离、油耗、CO2、CarbonCost 和单位订单碳排放。
