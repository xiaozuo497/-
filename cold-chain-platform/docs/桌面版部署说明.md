# 桌面版部署说明

## 当前形态

桌面版采用 Electron 外壳 + Docker Compose 本地服务：

- 桌面程序：`desktop/dist/win-unpacked/Cold Chain Platform.exe`
- 桌面快捷方式：`D:\zuoyiqing\Cold Chain Platform.lnk`
- 前端地址：`http://localhost:5173`
- 后端地址：`http://localhost:8000`
- 数据库：PostgreSQL Docker 容器
- 缓存/任务队列：Redis Docker 容器

桌面程序启动后会自动：

1. 检查 Docker 是否可运行。
2. 如果本地服务已经运行，直接进入系统。
3. 如果服务未运行，执行 `docker compose up -d --build`。
4. 等待 API 和前端健康后打开系统界面。

## 使用方式

双击桌面快捷方式：

```text
D:\zuoyiqing\Cold Chain Platform.lnk
```

或者直接运行：

```text
D:\zuoyiqing\cold-chain-platform\desktop\dist\win-unpacked\Cold Chain Platform.exe
```

## 重新生成桌面快捷方式

```powershell
cd D:\zuoyiqing\cold-chain-platform
powershell -ExecutionPolicy Bypass -File .\tools\create-desktop-shortcut.ps1
```

## 重新打包桌面版

```powershell
cd D:\zuoyiqing\cold-chain-platform\desktop
npm run pack
```

输出目录：

```text
D:\zuoyiqing\cold-chain-platform\desktop\dist\win-unpacked
```

## 前置条件

- Docker Desktop 已安装并运行。
- 当前用户能执行 `docker compose`。
- 本机端口 `5173`、`8000`、`5432`、`6379` 未被其他程序占用。

## 停止本地服务

可在桌面程序菜单中选择“系统 -> 停止本地服务”，也可以执行：

```powershell
cd D:\zuoyiqing\cold-chain-platform
docker compose stop
```
